Lesson 23

Lesson 23: Australian music analysis

Lesson 23 of 30, in Week 8 of Sound Detectives.

Learning intention

I can analyse an Australian work using elements and context.

Success criteria

tick them off as you go, they save on your device

Listen

Yothu Yindi, 'Treaty' (Radio Mix, official video) — blends traditional Yolŋu music with rock; rich land-rights context for a context-linked analysis.

What we are doing

  1. Listen to the work twice.
  2. Plan using both element prompts and context prompts.
  3. Write about how the elements are used and how the music reflects its context.
  4. Share and discuss using musical terminology.

Your task

Write a response linking the elements of music to the context of an Australian work.

Before you leave

How did context shape the way you heard this work?
