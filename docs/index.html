Lesson 6

Comparing 'Valerie'

Lesson 6 runs Wednesday 5 August, Period 5.

Learning intention

Learning intention: I can compare two versions of the same song using performing media and timbre.

Success criteria

  • I can name the voices and instruments I hear in each version.
  • I can describe the tone colour of each one using musical words.
  • I can write one similarity and one difference, and back each up with musical evidence.
